# Env Logging

This example demonstrates how to use the [`tracing`] crate with Serenity.

> **Tip:** `tracing` is a framework for instrumenting Rust programs to collect structured, event-based
diagnostic information. For more details, see the [`tracing` documentation].

In this example, we show how to use `tracing` crate macros to easily construct events at different
logging levels.

[`tracing`]: https://crates.io/crates/tracing
[`tracing` documentation]: https://docs.rs/tracing/latest/tracing/
