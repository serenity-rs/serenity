# Basic ping bot

This example showcases a basic ping bot.

Concepts introduced include:
- Creating an event handler struct and implementing the `EventHandler` trait
- Using the event handler to receive an event from the Gateway
- Configuring the Client using a bot token from the environment
- Setting the gateway intents (more details in [example 10])
- Building the Client and starting the bot
