# Message components

This example demonstrates how to use message components.

> **Note:** The components introduced in this example are [legacy message components]. The newer
components V2 (CV2) offer much more variety, but come with some limitations. [Learn more.]

In this example, you will create a message with a select menu and another with buttons, and you
will see how to receive and respond to component interactions.

[legacy message components]: https://docs.discord.com/developers/components/reference#legacy-message-component-behavior
[Learn more.]: https://docs.discord.com/developers/components/reference
