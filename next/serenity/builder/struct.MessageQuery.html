pub async fn execute( self, cache_http: impl CacheHttp, guild_id: GuildId, should_cache: ShouldCache, ) -> Result<MessageSearchResults>

Available on crate feature http only.

Executes message search in the guild.

If should_cache is Yes, then this method will fill the message cache for the guild, keeping only the most recent messages according to the value of max_messages for the cache.

If Discord returns a not-ready response, this method will automatically retry the query as needed until search results are received. If you need to impose a timeout on the retry logic, use [tokio::time::timeout] or similar.

Note: The user must have the Read Message History permission and the Message Content privileged intent to perform a search.

§Errors

Returns Error::Model if one or more query parameters exceed Discord’s limits. Returns Error::Http if the current user lacks permission.
