fn filter_event( &self, _context: &Context, event: Box<Event>, ) -> Option<Box<Event>>

Checks if the event should be dispatched or ignored. Returns Some(event) by default.

Returning None will drop the event and never process it.

Returning a mutated Some is a supported use case, but may cause contradictions to documented behaviour or otherwise cause unexpected errors within serenity/library consumers. Mutate with extreme caution.

§Warning

Similar to RawEventHandler, this method runs synchronously to the ShardRunner, keep runtime complexity low.
