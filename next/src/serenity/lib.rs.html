1//! Serenity is a Rust library for the Discord API.
2//!
3//! View the [examples] on how to make and structure a bot.
4//!
5//! Serenity supports bot user authentication via the use of [`Client::builder`].
6//!
7//! Once logged in, you can add an event handler to your client to dispatch [`Event`]s.
8//! This will allow you to recieve and handle events as you see fit. For example, an
9//! [`Event::MessageCreate`] event will be dispatched to you when a message is sent.
10//! Every event will give you access to a [`Context`], giving information about the event.
11//! See the [client's module-level documentation].
12//!
13//! The [`Shard`] is transparently handled by the library, removing unnecessary complexity. Sharded
14//! connections are automatically handled for you. See the [gateway's documentation][gateway docs]
15//! for more information.
16//!
17//! A [`Cache`] is also provided for you. This will be updated automatically for you as data is
18//! received from the Discord API via events. When calling a method on a [`Context`], the cache
19//! will first be searched for relevant data to avoid unnecessary HTTP requests to the Discord API.
20//! For more information, see the [cache's module-level documentation][cache docs].
21//!
22//! Note that, although this documentation will try to be as up-to-date and accurate as possible,
23//! Discord hosts [official documentation][docs]. If you need to be sure that some information
24//! piece is sanctioned by Discord, refer to their own documentation.
25//!
26//! ### Full Examples
27//!
28//! Full examples, detailing and explaining usage of the basic functionality of the library, can be
29//! found in the [`examples`] directory.
30//!
31//! # Installation
32//!
33//! Add the following to your `Cargo.toml` file:
34//!
35//! ```toml
36//! [dependencies]
37//! serenity = "0.12"
38//! ```
